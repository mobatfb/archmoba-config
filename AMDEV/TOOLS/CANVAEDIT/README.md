# CANVAEDIT

Editor visual por capas de PYRION.

## Estructura

- `canvaedit.py`: motor inicial de capas.
- `layers.json`: proyecto/capas actuales.
- `assets/`: imágenes, iconos y demás recursos gráficos.

## Capa inicial

La Capa 0 está reservada para el fondo oficial de PYRION.

Este módulo se mantendrá separado del ISO hasta que se decida integrarlo.
